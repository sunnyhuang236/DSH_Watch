# 装好之后怎么用（DSH Watch 用户指南）

适用：电脑上已装好 DSH、`dsh-watch` 插件和网关，手机已拿到 tunnel 地址与配对码。

## 1 手机第一次设置

1. iPhone Safari 打开电脑显示的 tunnel 地址（`https://xxxx.trycloudflare.com`）；
2. 点“分享”→“添加到主屏幕”；
3. **从主屏幕新图标打开**，不要只在 Safari 标签页里用；
4. 输入 8 位配对码；
5. 到“设置”页开启通知，并在 iOS 设置里允许通知。

## 2 日常使用

### 任务页
- 顶部显示连接状态和刷新按钮；
- 任务列表按状态分组：运行中 / 等待审批 / 等待回答 / 完成 / 失败；
- 点任意任务进入详情。

### 任务详情
- **时间与来源**：开始/最近活动/结束、执行 session、子代理数量、父任务、来源、代理状态；
- **费用**：DSH 只提供 token 时会显示“暂无数据”，不是 0；
- **轨迹（按轮次折叠）**：点“轮次 N”展开；最近一轮和异常轮默认展开；
- **审批卡**：出现“需要你的决定”时，可选“允许一次”或“拒绝”；
- **问答卡**：DSH 向你提问时，选择选项并提交。

### 提醒页
- 查看已收到的任务完成/失败/等待通知记录；
- 任务结束、失败、等待审批/回答时都会推送。

### 设置页
- 开启/关闭通知；
- 查看设备信息和配对状态；
- 退出配对/清除本机设备。

## 3 建议的验收流程

1. 在 DSH 里新建一个短任务，例如让它运行一条 `Start-Sleep -Seconds 10` 的命令；
2. 手机锁屏，等任务完成通知；
3. 点通知进入任务详情，确认状态、时间和轨迹正常；
4. 再让 DSH 执行一个需要审批的写操作，确认手机出现审批卡，点“允许一次”，任务继续；
5. 让 DSH 提一个问题，确认手机出现问答卡并提交答案。

## 4 常见问题

| 现象 | 处理 |
| --- | --- |
| 手机打不开 tunnel | 电脑上的 cloudflared 可能已停；重新 `npm run tunnel`，地址会变，需重新添加/配对 |
| 通知收不到 | 确认是从主屏幕图标打开、设置里已开启通知、iOS 通知权限已允许 |
| 任务不更新 | 点右上角刷新；确认电脑 DSH 和网关进程还在运行 |
| 审批后电脑还显示等待 | DSH 桌面客户端没有跨端广播，刷新/切换会话即可；手机决定已生效 |
| 费用一直“暂无数据” | DSH 当前只暴露 token，不提供费用字段；这是预期行为 |
| 手机不是同一 Wi-Fi | 不需要同一 Wi-Fi，手机走 tunnel 公网地址即可 |

## 5 安全提醒

- tunnel 地址和配对码只发给自己的手机，不要发群/公开；
- 配对码 5 分钟有效，过期重新生成；
- 不使用时可以停掉 cloudflared，减少公网暴露；
- 不要共享 `~/.dsh`、`state.json`、设备 token 或任何 API key；
- 本工具不修改 DSH 源码，也不改 `ui-theme` 等 UI 插件。
