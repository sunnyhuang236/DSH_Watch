```powershell
# 1) M1 插件

# 期望：ok=true、upstream.ok=true

# 3) 启动隧道（二选一）
npm run tunnel

# 记下输出的 https://<随机>.trycloudflare.com
```

- [ ] 插件 health 正常
- [ ] 网关 health 正常，`upstream.ok=true`
- [ ] 隧道地址可打开（电脑浏览器先访问 `/v1/health` 返回 200）

## 2 配对 + 安装（iPhone）

1. 电脑新开终端：`npm run pair`（打印二维码 + 8 位码）。
2. iPhone Safari 打开隧道地址 `/pair`（或扫描二维码），输入 8 位码，设备名填“iPhone 验收”。
3. 电脑终端按 `y` 确认；手机显示配对成功。
4. iPhone Safari 分享 → **添加到主屏幕** → 名称“DSH Watch” → 添加。
5. 从主屏幕图标打开（确认不是 Safari 标签页），进入设置页 → 点“开启通知” → 允许。
6. 设置页确认：安装状态“已安装”、通知权限“已允许”。
