# M3 演示录屏与截图清单（60 秒）

## 60 秒脚本

| 时间 | 画面 | 旁白要点 |
| --- | --- | --- |
| 0–10s | 配对页：输入电脑地址 + 8 位码 | “原生版与 PWA 共用同一套契约；先在同一 Wi-Fi 下配对。” |
| 10–25s | 任务列表：待处理/运行中/最近结束 + 统计 | “一眼看到是否需要我介入；状态不只靠颜色，带符号和文字。” |
| 25–40s | 任务详情：状态、当前步骤、摘要、时间、事件 | “点进任务能看到当前步骤和结果摘要，数据来自 DSH 同一个 m1-v1.1 API。” |
| 40–50s | 提醒记录：未读/全部已读/点击进详情 | “提醒记录本机保存；M3 展示版不含推送，锁屏提醒用 PWA 版。” |
| 50–60s | 设置：当前电脑/缓存/解除配对 | “免费签名 7 天；演示版仅局域网，不承诺日常使用。” |
